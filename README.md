# AllIn: Advanced Poker AI & Machine Learning Strategy Platform

AllIn is a production-grade **artificial intelligence** poker strategy system featuring advanced **machine learning** algorithms, **deep learning** concepts, and sophisticated **data science** methodologies. Built with **Monte Carlo CFR+**, **NumPy**, **Pandas**-compatible data processing, and modern **neural network** principles for game theory optimal (GTO) poker analysis.

---

## 🎯 Machine Learning & AI Overview

### 🧠 Artificial Intelligence Engine
- **Advanced Monte Carlo CFR+**: External sampling algorithm reducing computational complexity from **O(|S| × |A|)** to **O(|A|)**
- **Deep Strategy Learning**: **300,000 training iterations** across **5,878 unique information sets**
- **Neural Network-Inspired**: Multi-layer abstraction systems with **8 preflop + 6 postflop buckets**
- **Reinforcement Learning**: Self-play training with **regret minimization** and **policy optimization**
- **Data Mining**: Automatic discovery of **105 unique action patterns** from game tree exploration

### 📊 Data Science & Analytics
- **Big Data Processing**: **21.6M strategic decisions** analyzed with **pandas-compatible** data structures
- **Statistical Analysis**: **Entropy calculations**, **convergence metrics**, and **visit frequency distributions**
- **Performance Optimization**: **16.45 iterations/second** with linear memory scaling
- **Predictive Modeling**: **51.3% pure strategies**, **37.9% mixed strategies** for optimal game theory
- **Feature Engineering**: Sophisticated **card abstractions** and **action pattern encoding**

### 🔬 Machine Learning Architecture
```
Training Pipeline:
Random Sampling → Monte Carlo CFR+ → Feature Extraction → 
Strategy Optimization → Model Validation → Production Deployment
```

**Key ML Technologies:**
- **NumPy** for high-performance numerical computing
- **SciPy**-compatible statistical operations  
- **Scikit-learn** methodology for model validation
- **TensorFlow**-inspired architecture patterns
- **MLOps** practices with automated training pipelines

## 🛠 Getting Started

### Prerequisites
- **Python 3.8+** (with **data science libraries**)
- **Node.js 16+** (for **frontend visualization**)
- **Git** (for **version control**)
- **8GB+ RAM** (recommended for **ML training**)

### Quick Setup

#### 1. Repository Setup
```
git clone https://github.com/jianrontan/AllIn.git
cd AllIn
```

#### 2. ML Environment Setup
```
# Install Python ML dependencies
pip install flask flask-cors numpy phevaluator pandas scikit-learn

# Start AI inference server
cd backend/api
python strategy_api.py
```

#### 3. Frontend Dashboard
```
# Install visualization dependencies
cd frontend
npm install

# Start analytics dashboard  
npm run dev
```

### 🎓 Training Your Own AI Models

#### Quick Training (Development)
```
cd backend/bot
python -c "
from tests.run_blueprint_trainer import run_enhanced_training
results = run_enhanced_training(1000)  # 1K iterations
print('AI model training completed!')
"
```

#### Production Training (Full Scale)
```
cd backend/bot
python -c "
from tests.run_blueprint_trainer import run_enhanced_training
results = run_enhanced_training(300000)  # 300K iterations, ~5 hours
"
```
