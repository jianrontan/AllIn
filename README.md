# ALLIN: Play to Win

ALLIN is a web-based poker learning and playing platform designed to help users master poker strategy through interactive gameplay and, in the future, advanced AI opponents.

---

## Milestone 1 Submission

### Level of Achievement: Apollo

- **Basic frontend prototype:**  
  - Single landing page with branding and a button that navigates to a second page.
  - No backend or gameplay logic implemented yet.

---

### Project Scope

**One-Sentence Scope:**  
A poker learning platform with a user-friendly interface, aiming to eventually support play against AI and ML-based poker bots.

**Descriptive Scope:**  
For Milestone 1, the project consists of a simple React frontend with a landing page displaying the project logo and a single button. Clicking the button routes the user to a second page. There is currently no backend integration or poker gameplay. The project is structured to support future expansion, including Supabase/PostgreSQL backend and integration of poker bots (Kuhn and Leduc with CFR, already developed separately but not yet included in this repository). The focus for this milestone is establishing the user-facing foundation and project structure for rapid iteration in later milestones.
